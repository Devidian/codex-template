---
name: roadmap-management
description: Use when planning a development phase or updating its acceptance status.
---

Use `docs/roadmap/roadmap.md` as the overview and one concise document in `docs/roadmap/active/` for active work. Record objective, scope, acceptance criteria, dependencies, risks, status, and task checklist. Update the active document as work proceeds. Archive only after explicit acceptance; do not create a branch for every small task.

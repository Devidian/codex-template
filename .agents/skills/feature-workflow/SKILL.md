---
name: feature-workflow
description: Use when starting or continuing feature, fix, or chore work and preparing its pull request.
---

Read `AGENTS.md` and `docs/development/branching.md`. Check branch and worktree before edits. On `main`, create one appropriately named development branch for new work; on an existing development branch, continue there. Keep the change scoped, run targeted checks, update relevant docs and `CHANGELOG.md`, and prepare a Conventional Commit PR title. Do not merge without explicit acceptance.

---
name: code-review
description: Use for a requested change review or a pre-acceptance correctness review.
---

Review the diff against the task and `AGENTS.md`. Focus on behavior, regressions, failure handling, test quality, maintainability, and relevant security exposure. Report actionable findings first with file locations and severity; distinguish verified defects from plausible risks. State any remaining validation gap. Do not treat a passing CI result as human acceptance.
